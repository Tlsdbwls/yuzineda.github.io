SUMBI

수중 풍경과 운항 정보를 함께 바라보는 잠수정 GUI 콘셉트. 빛의 링, 유리 HUD, 손 안의 조종기로 정보를 나누고 탐사와 경고 상황의 우선순위를 설계했습니다.

DISCIPLINE
DEVICE GUI · INTERACTION
DESIGN SCOPE
인터랙션 기획 · GUI 디자인
PROJECT TYPE
SUBMERSIBLE GUI CONCEPT

SUMBI · 잠수정 GUI 콘셉트

01 CONTEXT

바다를 보면서, 상태를 읽기

모든 정보를 한 화면에 모으면 시선이 수중 환경에서 멀어진다는 문제의식에서 출발했습니다. 조종과 안내를 이어가면서도 남은 잠항 시간과 심도를 빠르게 살필 수 있도록, 정보의 위치와 우선순위를 나누는 것을 목표로 삼았습니다.

02 DESIGN APPROACH

빛의 링 · 유리 HUD · 조종기

줄어드는 Halo의 길이로 잔여 상태를 표현하고, 남은 잠항 시간은 화면 중앙에서 가장 크고 밝게 읽히도록 배치했습니다. 심도는 왼쪽, 방위·자세·소나는 오른쪽의 보조 계기로 정리하고, 조종기에는 모드와 제어 상태를 모았습니다.

03 DESIGN DETAILS

경고에서는 다음 행동을 앞에

경고 화면은 붉은 빛의 링과 중앙의 남은 시간으로 주의를 모으고, ‘지금 상승’이라는 행동과 조작 방법을 함께 제시했습니다. 일반 계기는 주변으로 물러나게 해, 탐사 화면과 다른 우선순위가 드러나도록 구성했습니다.

04 OUTCOME

상황에 따라 달라지는 정보의 무게

탐사 메인 화면 1차와 경고 화면 2차를 통해, 같은 운항 정보도 상황에 따라 크기·밝기·색·위치를 달리하는 방식을 구체화했습니다. 화면의 수치와 경고 조건은 콘셉트를 설명하기 위한 예시이며, 실제 운항 성능을 검증한 결과는 아닙니다.
